# Solar AI
<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
Software simulation of solar surplus decisions and a conversational assistant grounded in the current energy state. No physical control or measured savings are claimed.

## Users
Inferred from the existing project and execution brief: prototype demonstrators and reviewers exploring solar scenarios. No production operator research is claimed.

## Capabilities and Constraints
Seven routes separate the landing, overview, simulator, assistant, evaluation, case study and planned hardware pipeline. Simulation, language, decisions and bounded chat persist during client navigation, not reloads. Preserve existing API contracts and provider transport. The deterministic fallback distinguishes balance from shortage using computed net, excludes zero-capacity storage and recommends advisory curtailment when surplus has no eligible sink. Raspberry Pi and sensor integration are future work.

## Brand Commitments
The latest requested direction separates a concise Home gateway, a read-only simulation overview with an edit link, and a dedicated Simulator containing all inputs. Retain the premium daylight visual language, conceptual Home illustration, purposeful overview energy flow and progressive explanations. No gradients, glow or emoji clutter. Arabic and English, responsive navigation and bounded content width. Existing product name: شمسي الذكي / Solar AI.

## Accessibility & Inclusion
RTL/LTR layout, semantic controls, visible keyboard focus, reduced motion support and mobile navigation.
